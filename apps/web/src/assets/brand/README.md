# Official Informatics logo

- `informatics-logo-original.png` — the file supplied by the project owner on 2026-10-24, unchanged (764×401, white wordmark on navy #0B265D).
- `informatics-logo.png` — the same artwork cropped to the wordmark with a small margin (385×63). No redrawing, recolouring or resizing. This is the file the app uses (`src/components/Brand.tsx`).

The artwork is a white wordmark on navy, so it is only placed on navy surfaces. Do not substitute a recreated logo (SRS V1.5 §3). If a vector (SVG) or higher-resolution version becomes available, save it as `informatics-logo.svg` and it will be preferred automatically.
